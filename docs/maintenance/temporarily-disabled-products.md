# 一時非表示の商品（管理記録）

公開中の診断で、購入できる販売先を確認できないなどの理由で一時的に非表示（`enabled: false`）にした商品の記録です。

- 商品データ（商品ID・型番・仕様・価格・priceRange・販売URL）は削除・変更せず、`enabled` だけを `false` にしています。
- 非表示の商品は、診断結果（通常ランキング・補完候補・そのほかの候補）にも、比較商品一覧にも出ません。
- 再掲載は自動では行いません。再掲載するときは「再掲載の手順」に従ってください。
- 表示中の商品で判明している不具合は `docs/known-product-issues.json` で管理しています（このファイルは非表示にした商品だけを扱います）。

## 再掲載の手順

1. 下の「再掲載の条件」をすべて満たす販売先を、販売ページまたは楽天API（`npm run rakuten:search`）で改めて確認する。確認できなければ再試行を繰り返さず、非表示のままにする。
2. 販売URLを差し替える場合は、対象商品の楽天アフィリエイトURL（`hb.afl.rakuten.co.jp`）だけを変更する。価格・priceRange を変える必要がある場合は、別途承認を得る。
3. `src/data/diagnoses/<診断>.ts` と `data/diagnosis-specs/<診断>.json` の両方で `enabled` を `true` に戻す（JSON は `"enabled": false` の行を削除する。省略時は `true`）。
4. 対象診断の全回答パターンを変更前と比較し、必須条件違反0件・表示結果数の異常0件・他商品のスコアと条件判定の差分0件を確認する。
5. 比較商品一覧の件数（初期表示3件＋開閉内）と、画面・診断動作を確認してから公開する。
6. 公開後、この記録から該当商品を削除する（履歴は git に残る）。
